
# 🦠 COVID-19 Global Data Analysis

Welcome to my COVID-19 Data Analysis project! This repository contains curated datasets and a personal analysis of the global impact of the COVID-19 pandemic, based on data from **Our World in Data**.

## 📁 Dataset Source
This project uses the official dataset from [Our World in Data](https://github.com/owid/covid-19-data), updated regularly to track cases, deaths, tests, vaccinations, and more.

## 🧠 Objective
To explore and visualize trends in COVID-19 cases, deaths, and vaccinations globally and by country. The goal is to gain insights into how different countries responded and how the pandemic evolved over time.

## 🛠 Tools Used
- Python
- Pandas
- Matplotlib & Seaborn
- Jupyter Notebook

## 📊 Key Insights
- Growth of confirmed cases and deaths over time
- Country-wise comparison of case trends
- Vaccination trends and their correlation with decline in cases
- Visual timelines of pandemic waves

## 📌 How to Run

1. Clone the repository
2. Open the Jupyter notebook in your environment
3. Install dependencies with `pip install -r requirements.txt`
4. Run the notebook and explore the insights
